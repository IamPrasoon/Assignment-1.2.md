Objective: To set up a web development environment.

Steps:

Install VS Code and Node.js (LTS).

Install Live Server and Prettier extensions in VS Code.

Create a folder named web-development-practice.

Create three files:

index.html

style.css

script.js

Write basic HTML code in index.html:


<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>My first website.</p>
</body>
</html>

Right-click index.html and select Open with Live Server.

Open the terminal and check:

node -v
npm -v

Result: The website opens in the browser, and the terminal displays Node.js and npm versions.
